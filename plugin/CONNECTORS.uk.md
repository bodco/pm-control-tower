# Позначки `~~` і конектори

[In English](CONNECTORS.md)

## Як це працює

`~~щось` це місце, куди підставляється **твоє** значення. Плагін не знає ні твого
Notion, ні твоїх шляхів, тому всі такі місця позначені явно.

Найпростіше: скажи Claude «налаштуй плагін pm-control-tower під мене». Він знайде
всі позначки і проведе по них питаннями.

## Що треба підставити

| Позначка | Що це | Де взяти |
|---|---|---|
| `~~notion-reports-db` та решта `~~notion-*-db` | ID баз у **твоєму** Notion | відкрий базу, візьми ID з URL |
| `~~notion-project-page-id` | сторінка твого проєкту в базі Projects | з URL сторінки |
| `~~notion-workspace-page-id` | сторінка воркспейсу в базі Workspaces | з URL сторінки |
| `~~notion-page-id` | окремі сторінки, на які посилаються скіли | створи їх і візьми ID |
| `~~home-folder` | твоя домашня папка | `/Users/ivan` |
| `~~jira-mcp-path` | де лежить локальний MCP-сервер Jira | див. нижче |
| `~~sentry-host`, `~~service-a` … `~~service-g` | твій Sentry і назви сервісів | тільки якщо користуєшся `stability-scan` |
| `~~client-roadmap-url`, `~~client-tasks-db-url` | борд клієнта, якщо він у нього є | тільки для `thread-ticket-sync` |
| `~~org` | префікс імені LaunchAgent | `com.ivan.mail-collector.plist` |

## MCP-сервери в комплекті

У плагіні є `.mcp.json` з двома серверами під спільну інфраструктуру компанії.
Секретів там немає: команда читає значення з твого `secrets.env`.

**Confluence** працює одразу, потрібен лише `uv` (`brew install uv`) і токен
у `CONFLUENCE_TOKEN`.

**Jira** потребує одного кроку руками: локальний MCP-сервер треба склонувати
собі, а шлях до нього підставити замість `~~jira-mcp-path`. Сам сервер у бандл
не входить, це чужий код. Питай у автора плагіна, звідки його брати.

## Офіційні конектори

| Категорія | Для чого | Де вмикати |
|---|---|---|
| Notion | памʼять усієї системи, без неї скіли не мають куди писати | Settings → Connectors |
| Slack | збір тредів, `daily-team-prep`, `slack-collector` | Settings → Connectors |
| Gmail і Calendar | `weekly-overview`, денні звіти | Settings → Connectors |

Якщо конектора немає, скіли не падають. Вони пишуть у звіт рядок про недоступне
джерело і роблять решту. Це закладено навмисно і називається graceful degradation.
