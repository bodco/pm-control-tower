# 17. Live Tips: moved

[Українською](../uk/17-live-tips.md) · [Back to contents](README.md)

The call co-pilot is a separate product now: **[Live Tips](https://github.com/bodco/live-tips)**, the
macOS app and the `live-tips` skill with its local recorder. The full guide is
[docs/en/live-tips.md](https://github.com/bodco/live-tips/blob/main/docs/en/live-tips.md) there, and the
product page is [tower.bodco.pm/live-tips](https://tower.bodco.pm/live-tips/).

Live Tips works on its own. With this framework it also reads `projects/<slug>.md` (people, Notion pages,
the current state) and writes the meeting page into the Meetings database of the Notion template.

Releases up to 0.5.8 stayed in this repository's [releases](https://github.com/bodco/pm-control-tower/releases);
the history of the code moved with it.
